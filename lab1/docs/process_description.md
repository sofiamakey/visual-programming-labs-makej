# Бизнес-процесс: Онлайн-бронирование номера в отеле

### Участники (роли):
1. Клиент — выбирает даты и категорию номера.
2. Сайт / Система бронирования — проверяет наличие и рассчитывает цену.
3. Банковский шлюз — проводит оплату.
4. База данных отеля — фиксирует бронь.
5. Администратор отеля — подтверждает заселение.

### Описание процесса:
1. Клиент заходит на сайт отеля, указывает даты заезда и выбирает категорию номера.
2. Система отправляет запрос в базу данных отеля для проверки доступности номеров.
3. Ветвление 1: Если свободных номеров на выбранные даты нет, система предлагает изменить даты; если номера есть, клиент переходит к бронированию.
4. Клиент вводит свои паспортные и контактные данные.
5. Клиент подтверждает бронь и переходит на защищенную страницу оплаты.
6. Ветвление 2: При отказе банка система предлагает повторить платеж с другой карты; при успешной оплате формируется ваучер.
7. Параллельные действия: Пока банк подтверждает транзакцию, система параллельно ставит временную блокировку на выбранный номер в базе данных отеля.
8. Система генерирует квитанцию с кодом бронирования.
9. Клиент получает подтверждение бронирования и ваучер на электронную почту.
10. Администратор отеля видит бронь в программе управления и резервирует ключ к моменту заезда.
